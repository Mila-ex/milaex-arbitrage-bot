# Mila-ex Arbitrage Bot 🪙🤖

A simple, multi-language cross-exchange arbitrage bot built using the powerful [Mila-ex API](https://api.milaex.com/api-docs/index.html). This example demonstrates how developers can quickly retrieve real-time market data from multiple cryptocurrency exchanges to identify profitable arbitrage opportunities.

## 🔧 Features

- Unified access to multiple crypto exchanges via Mila-ex
- Live BTC/USDT price tracking across Binance, Coinbase, KuCoin, and Kraken
- Real-time arbitrage detection with customizable profit threshold
- Fully implemented in:
  - Python
  - Node.js (JavaScript)
  - C# Console App

## 📦 Requirements

You will need a **free Mila-ex API key**. Register here:  
👉 [https://milaex.com](https://milaex.com)

---

## 🚀 How to Run

### 🐍 Python
1. Install requirements:  
   `pip install requests`

2. Add your API key to `arbitrage_bot.py`.

3. Run:  
   `python arbitrage_bot.py`

---

### 🟨 JavaScript (Node.js)
1. Install requirements:  
   `npm install axios`

2. Add your API key to `arbitrage_bot.js`.

3. Run:  
   `node arbitrage_bot.js`

---

### 🟦 C# (Console App)
1. Compile and run with `dotnet run`.
